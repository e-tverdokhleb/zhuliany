# Zhuliany House — Fusion 360 Parametric Model

Цей репозиторій — спільна робоча зона для параметричної моделі будинку у Fusion 360.

## Основна схема роботи

1. ChatGPT допомагає структурувати дані, аналізувати БТІ/фото, формувати вимоги та перевіряти логіку.
2. Claude Code працює безпосередньо з цим репозиторієм:
   - редагує Python-код;
   - підтримує структуру даних;
   - генерує/покращує Fusion 360 scripts/add-in;
   - веде TODO щодо невідомих розмірів.
3. Fusion 360 запускає код і будує параметричну модель.
4. Усі нові точні виміри вносяться у `data/house_config.json`.

## Перший запуск Claude Code

Відкрий цей репозиторій у Claude Code та дай команду:

> Прочитай `CLAUDE.md` і `prompts/phase1_parametric_shell.md`. Не вигадуй геометрію. Спочатку перевір структуру проєкту, потім реалізуй Phase 1.

## Дані

- `data/plans/` — БТІ, плани, схеми.
- `data/photos/` — фотографії кімнат.
- `data/measurements/` — ручні заміри, таблиці, нотатки.
- `data/house_config.json` — головна машинозчитувана конфігурація геометрії.

## Правило точності

Невідомі або приблизні розміри повинні залишатися явно позначеними як `UNKNOWN`, `APPROX` або `TODO`. Не перетворювати припущення на точні дані.
