# Phase 1 — Parametric shell

Побудуй мінімальну робочу параметричну систему для Fusion 360.

## Вимоги
1. Прочитай `CLAUDE.md`.
2. Прочитай `data/house_config.json`.
3. Не заповнюй `walls`, `doors`, `windows` вигаданими координатами.
4. Створи архітектуру, яка дозволяє додати їх пізніше без переписування ядра.
5. Створи user parameters з `defaults`.
6. Реалізуй централізовану конвертацію mm -> Fusion internal units.
7. Реалізуй логіку створення/пошуку компонентів.
8. Реалізуй валідатор конфігурації:
   - UNKNOWN/APPROX -> warning;
   - missing required field -> clear error.
9. Підготуй генератори: walls, openings, chimney.
10. Якщо конфігурація ще не має геометрії, скрипт не повинен вигадувати будинок.

## Результат першого проходу
Покажи:
- які файли змінив;
- які параметри створюються;
- як додати першу стіну в JSON;
- як запустити в Fusion 360;
- які дані потрібні для першої реально побудованої геометрії.
